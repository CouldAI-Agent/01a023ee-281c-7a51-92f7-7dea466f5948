# Chat App

A modern, cross-platform chat application built with Flutter.

## Features
- **Real-time UI updates**: Smooth message insertion with an automatic reverse-scrolling list.
- **Auto-reply Bot**: A simulated bot replies instantly to your messages so you can test the UI natively.
- **Adaptive Design**: Distinct chat bubble stylings for sent and received messages, constrained intelligently to avoid overflowing wide screens.
- **Cross-Platform**: Fully compatible with iOS, Android, Web, and Desktop environments out of the box.
- **Dark & Light Mode**: Supports your system's native brightness theme beautifully.

## Tech Stack
- Flutter
- Dart
- Material 3 Design System

## Getting Started

1. Ensure you have Flutter installed on your machine.
2. Clone this repository and navigate to the project directory.
3. Fetch the dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
